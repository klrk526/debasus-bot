# 🍽️ Debasus Bot

Telegram-бот для ресторана «Дебассус» (Воронеж).

Помогает гостям:
- 🔥 Узнать акцию дня
- 📍 Найти ресторан
- 📞 Забронировать столик

Принцип работы: автоматизация бронирования столиков через телеграмм-бота, а не через сотрудника ресторна
Как это происходит?
1. Гость выбирает дату, время и количество человек
2. Бронирование приходит в лс к менеджеру/администратору
3. Менеджер/администратор записывает бронь в список броней на тот день, на который забронирован столик
